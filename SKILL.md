# Hooks Meta Ads · Blanko Studio

Esta skill es licenciada: las instrucciones completas están en el servidor de Blanko Studio.

1. Llama a la herramienta `run_playbook` del conector **Blanko Pack Copys** con `skill: "hooks-meta-ads"`.
2. Sigue al pie de la letra las instrucciones que devuelva para hacer la tarea del usuario.
3. Si la herramienta devuelve un error de licencia o de token, muéstrale al usuario ese mensaje tal cual y no intentes hacer la tarea por tu cuenta.
4. Si el conector no aparece, dile al usuario que primero use la skill `configurar-token`.
