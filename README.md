# Blanko Studio · Marketplace de skills

Para instalar el **Pack Copys Meta Ads**:
1. En Claude, ve a Customize → plugins → Add marketplace y pega la URL de este repositorio.
2. Instala el plugin **blanko-pack-copys**.
3. Agrega un conector personalizado con la URL personal que recibiste por correo al comprar.

Las skills requieren una licencia activa.
